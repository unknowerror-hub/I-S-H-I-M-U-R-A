# 🪐 ISHIMURA // ENTERPRISE AI VULNERABILITY & INTEGRITY CONTEXT

**ISHIMURA** — это автономный программный комплекс класса Next-Generation Vulnerability Management и проактивной защиты (IPS), спроектированный для развертывания на «голом железе» или виртуальных машинах под управлением **Ubuntu 24 LTS** без использования Docker/контейнеризации. Система ориентирована на максимальную производительность, работу напрямую с ядром ОС и создание монолитных дистрибутивов безопасности.

---

## 🛠 Подробная спецификация боевых модулей

### 1. 🎭 Arlechino [Ядро СУБД & Авторизация]
*   **Технологический стек:** PostgreSQL, Python, Psycopg2.
*   **Принцип работы:** Модуль является главным координатором данных. При первичной инсталляции он нативно разворачивает кластер СУБД, создает изолированного пользователя и автоматически транслирует схемы таблиц для всех остальных подсистем.
*   **Функции:** Генерирует уникальный 64-символьный межмодульный мастер-токен авторизации (`system_token.key`) с правами `0600` для предотвращения несанкционированного межпроцессного взаимодействия. Включает интерактивную SQL-консоль и инструменты обслуживания (`VACUUM`, `REINDEX`).

### 2. 🦊 Hatsumi [Центральный интерфейс & Операционная панель]
*   **Технологический стек:** PHP 8.x, Vanilla JavaScript, CSS3 Cyberpunk Engine.
*   **Принцип работы:** Главная административная панель управления с двухпанельной асинхронной архитектурой. Левая консоль отвечает за навигацию, правая — за вывод рабочих экранов без перезагрузки страницы.
*   **Функции:** Реализует строгую ролевую модель. При первом запуске принудительно заставляет сменить дефолтные учетные данные `admin/admin`, хэшируя новые пароли по алгоритму `PASSWORD_BCRYPT`. Оснащена светодиодной индикацией состояний демонов и синим неоновым пульсом при фиксации фоновых событий.

### 3. 🕷 Arachna [Многопоточный асинхронный RAW-сканер]
*   **Технологический стек:** Pure C (RAW-сокеты), Python (ThreadPool), `ipaddress`.
*   **Принцип работы:** Разделен на два слоя. Низкоуровневое C-ядро формирует кастомные TCP SYN-пакеты вручную, минуя стандартный сетевой стек Linux, что снижает нагрузку на CPU до нуля. Высокоуровневая обвязка на Python управляет конкурентными потоками.
*   **Функции:** Сканирование диапазонов CIDR (`/24` и др.) или загружаемых списков `txt/csv`. Асинхронно парсит баннеры ответов, сопоставляет их с локальной базой сигнатур `vuln_db` (более 140,000 записей) и в реальном времени транслирует ход выполнения через прогресс-бар в Hatsumi.

### 4. 🌸 Miko [ИИ-Аналитик & Резонатор уязвимостей]
*   **Технологический стек:** Python, Локальные ИИ-модели контекстного анализа, CSV-генераторы.
*   **Принцип работы:** Извлекает сырые логи сканирования Arachna из СУБД и пропускает их через аналитический ИИ-контур.
*   **Функции:** Сопоставляет версии ПО с онлайн-базами уязвимостей CVE и репозиториями PoC на GitHub. Генерирует структурированные по IP-адресам пошаговые рекомендации по закрытию уязвимостей (патчинг конфигураций, правила файрвола) и выгружает отчеты в один клик.

### 5. 💀 Terror [Синтезатор боевых векторов атаки]
*   **Технологический стек:** Python, Socket API, GitHub Search API, GNU Bash.
*   **Принцип работы:** На основе обнаруженных уязвимостей и CVE-идентификаторов осуществляет динамическую компиляцию полностью рабочих атакующих скриптов в формате `.py`.
*   **Функции:** Ищет готовые PoC на GitHub и выгружает их локально. Запускает асинхронный TCP-слушатель (Listener). При успешной эксплуатации уязвимости модуль автоматически перехватывает управление, открывает реальную сессию `Reverse Shell` с пораженным хостом и переводит веб-интерфейс в интерактивный CLI-режим.

### 6. 👁 Sadako [Метрики ядра & Телеметрия]
*   **Технологический стек:** Python, Linux Kernel Sysfs API (`/proc`).
*   **Принцип работы:** Фоновый демон сбора телеметрии. Не использует внешних зависимостей, считывая состояние ресурсов напрямую из структуры ядра.
*   **Функции:** Мониторинг CPU (`/proc/stat`), RAM и Swap (`/proc/meminfo`), HDD. Рассчитывает загрузку ядра сетевой карты по объему обрабатываемых прерываний (`IRQ/s`), фиксируя аномалии при пиковых нагрузках во время работы сканера Arachna.

### 7. 🛡 Lamia [ИИ-IPS Защита сетевого уровня]
*   **Технологический стек:** Pure C (RAW-инъекции), Python (ИИ-фильтр).
*   **Принцип работы:** Работает на уровне сетевого интерфейса, перехватывая входящие пакеты до их обработки стандартным Netfilter (iptables).
*   **Функции:** Автоматически считывает из СУБД IP-адреса всех легитимных нод кластера Ishimura и вносит их в белый список. ИИ-алгоритм выявляет сигнатуры зловредного трафика и попытки сканирования или повреждения модулей, транслируя атаки на неоновую панель в реальном времени.

### 8. 🌀 Kira [Кластеризация & Коммуникационные шлюзы]
*   **Технологический стек:** Python, SMTP, Telegram Bot API.
*   **Принцип работы:** Центральный оркестратор масштабирования и оповещений. Позволяет переводить тяжелые ИИ-вычисления модулей (Miko, Lamia) с CPU на мощности видеокарт NVIDIA (CUDA) или AMD (ROCm).
*   **Функции:** Автоматически разворачивает и связывает систему в отказоустойчивый горизонтальный кластер при указании IP новых серверов. Управляет интеграцией с Telegram (уведомления о критических взломах или атаках) и SMTP.

### 9. 🛰 Oraculus [Инвентаризатор топологии]
*   **Технологический стек:** Python, Linux Network Sysfs.
*   **Принцип работы:** Модуль инспекции физического уровня. Автоматически определяет сетевое оборудование хоста, MAC-адреса и состояние линков (`UP/DOWN`). Предоставляет веб-интерфейс для изменения IP-адресов всей инфраструктуры.

### 10. 🎒 Ashka & Mifiko [Теневой бэкап & Самовосстановление кодовой базы]
*   **Технологический стек:** Python, SHA-256 Crypto-Engine, Linux Crontab.
*   **Принцип работы:** Контур живучести системы. 
*   **Функции:** **Ashka** при инсталляции создает скрытый побайтовый теневой слепок всех скриптов и файлов системы в `/opt/ishimura/.shadow_storage`. **Mifiko** каждые 5 минут сверяет хэши SHA-256 рабочего дерева с теневой копией. При обнаружении подмены кода или несанкционированного изменения прав учетных записей Mifiko отправляет алерт в Hatsumi и позволяет откатить и восстановить оригинальный файл из тени в 1 клик.

## 💻 Полноцикловая инструкция по установке под Production

Система разворачивается на чистой операционной системе **Ubuntu 24 LTS**. Скрипт автоматической инсталляции самостоятельно поднимет веб-сервер, настроит СУБД, скомпилирует бинарные уязвимости на C и сконфигурирует фоновые демоны контроля.

### Шаг 1: Подготовка окружения и клонирование
Перенесите все исходные файлы проекта строго в каталог `/opt/ishimura/`:
```bash
sudo mkdir -p /opt/ishimura
# Переместите файлы в эту директорию
cd /opt/ishimura/
```

### Шаг 2: Запуск инсталлятора в 1 клик
Запустите главный конфигурационный скрипт:
```bash
sudo bash install.sh
```

### Шаг 3: Процесс интерактивной настройки
В ходе выполнения инсталлятор запросит у вас два критических параметра:
1.  **Пароль администратора веб-панели:** Будет зашифрован по алгоритму `BCRYPT` и применен для учетной записи `admin` в панели Hatsumi.
2.  **Мастер-пароль СУБД:** Установит пароль для пользователя `postgres` и создаст изолированную базу данных `ishimura_db`.

### Шаг 4: Разрешение автономного запуска Arachna без пароля
Чтобы веб-интерфейс мог активировать RAW-сканирование на уровне сетевой карты, предоставьте пользователю веб-сервера беспарольный доступ к оркестратору. Откройте файл привилегий:
```bash
sudo visudo
```
В самый конец файла добавьте строго одну строчку:
```text
www-data ALL=(ALL) NOPASSWD: /usr/bin/python3 /opt/ishimura/modules/arachna/core.py *
```
Сохраните файл (`Ctrl+O`, `Enter`, `Ctrl+X`).

## ⌨️ Использование консольного интерфейса Kuruma

Если доступ к веб-интерфейсу Hatsumi ограничен или заблокирован, вы можете полностью контролировать систему прямо через SSH-сессию. Утилита `kuruma.py` автоматически добавлена в системный путь вызова.

*   **Вызов интерактивного неонового меню:**
    ```bash
    ishimura
    ```
*   **Вызов встроенного справочника и флагов автоматизации:**
    ```bash
    ishimura --help
    ```
*   **Быстрая проверка жизненного цикла демонов:**
    ```bash
    ishimura --status
    ```

## 🔒 Безопасность и контур автозапуска
*   **Права доступа:** Межмодульный ключ авторизации `system_token.key` закрыт правами `chown root:root` и `chmod 600`. Доступ извне полностью заблокирован.
*   **Автозапуск:** Мониторинг Sadako, резервные слепки Ashka и контроль целостности Mifiko прописаны в системный планировщик `crontab` суперпользователя и начинают функционировать автоматически сразу после включения или перезагрузки сервера.
